# ⚡ NEON OVERDRIVE // Cyber Arena

A fast-paced, standalone top-down cyber arena shooter built purely with **Vanilla HTML5 Canvas & JavaScript**—featuring custom particle physics, procedural audio synthesis, and zero external dependencies.

---

### ✨ Key Features

- **Zero Dependencies**: Runs natively in any modern web browser within a single, self-contained HTML file.
- **Dynamic Arsenal**:
  - `Pulse Rifle`: High-velocity, rapid-fire precision plasma.
  - `Scattergun`: Wide-spread kinetic burst ideal for crowd control.
  - `Railgun`: Instant, multi-target piercing laser powered by ray-segment intersection physics.
- **Reflex Mechanics**: *Phase Dash* granting invincibility frames (i-frames) and high-speed repositioning with visual afterimage trails.
- **Procedural Web Audio Engine**: All sound effects (gunfire, detonations, dash hums) are synthesized dynamically on the fly via the Web Audio API—no external `.mp3` or audio assets required.
- **Combat Polish & Telemetry**: Integrated reactive screen shake, particle systems, floating damage numbers, combo multiplier system, and live aim accuracy tracking.

### 🎮 Controls

| Key | Action |
| :--- | :--- |
| `W`, `A`, `S`, `D` | Character Movement |
| `Mouse / Left Click` | Aim & Fire |
| `Space` / `Shift` | Phase Dash (Invulnerable) |
| `1`, `2`, `3` or `Q` | Cycle / Switch Weapon |
